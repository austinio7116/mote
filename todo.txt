1. Taxi fares — DONE (see README "Taxi fares")
   Hail -> pickup -> drop -> pay, with a streak multiplier. Implemented as its
   own loop rather than a mission type: phone jobs are started by walking to a
   phone box, which you cannot do from the driver's seat.

2. Traffic that notices you — DONE (see README "Traffic that sees you")
   player_ahead() mirrors car_ahead()'s lane test at the player on foot; cars
   brake to a stop with their brake lights on. One driver in five never brakes,
   derived from the car slot, so stepping into the road stays a gamble.

3. Secret building hideaways — DONE (see README "Hideaways")
   Two unmarked foot-only bays per city, carved into buildings in the spare
   NGARAGE slots. Hold a cache; bleed heat at 0.3 stars/s; blown by any
   officer within 11 m of the mouth.

4. Cars stop at zebra crossings — DONE (see README "Traffic that sees you")
   crossing_ahead() tests for a ped standing on a g_zebra tile in a 4.5 m
   corridor ahead. Same reckless 1-in-5 rule as the player case.
